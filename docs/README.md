# Documentação — Tutor de Escalas

Registro do andamento e da evolução do app. Mantido junto com o código.

## Índice

- [progresso.md](progresso.md) — linha do tempo, decisões e status atual.
- [evidencias/](evidencias/README.md) — telas, testes e builds comprovando o que foi feito.

## Como ler

1. Comece por **progresso.md**: mostra as fases, o que foi decidido e o que falta.
2. Para verificar algo, veja **evidencias/**: cada funcionalidade tem uma captura, cada build tem tamanho e hash.

## Convenções

- Datas no formato AAAA-MM-DD.
- Cada entrada de progresso registra o motivo da decisão, não só a mudança.
- Evidências são geradas por script (ver evidencias/README.md), para poderem ser refeitas.
